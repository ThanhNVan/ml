# Course 2: Neural Networks and Deep Learning

Move from logistic regression and vectorized calculus to shallow and deep fully connected neural networks.

## What you should be able to do

Implement forward propagation, loss, backpropagation, and parameter updates with dimensions that work across many examples.

## Learning path

### [Week 1: What neural networks learn](week-1/week.md)

The introductory lectures show neural networks as supervised learning systems, discuss applications and data scale, and frame the rest of the course.

### [Week 2: Logistic regression and vectorization](week-2/week.md)

Binary classification provides the smallest useful model. Computation graphs, derivatives, gradient descent, NumPy vectorization, and broadcasting prepare the notation used later.

### [Week 3: A shallow network](week-3/week.md)

A hidden layer adds nonlinear representation learning. The week covers activations, matrix forms for many examples, backpropagation, and random initialization.

### [Week 4: Deep networks](week-4/week.md)

Stack layers while tracking tensor shapes, reuse forward and backward blocks, distinguish learned parameters from hyperparameters, and understand why depth can be useful.
