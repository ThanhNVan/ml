# Course 2, week 1: Neural network orientation

[Course overview](../course.md) · [Weekly test](<../../../test/course 2. Neural Networks and Deep Learning/week-1/week-test.md>) · [Weekly answers](<../../../test/course 2. Neural Networks and Deep Learning/week-1/week-answers.md>)

## Week at a glance

What neural networks learn. The introductory lectures show neural networks as supervised learning systems, discuss applications and data scale, and frame the rest of the course.

## Detailed notes

- A neural network composes simple transformations into a trainable input/output map. Hidden units can learn features rather than requiring every useful feature to be specified manually.

- The examples span structured data, images, audio, and text. The choice of network architecture depends on data type and the output needed.

- The lectures relate deep learning progress to data availability, computation, and algorithmic improvements. More data is especially useful when the model has enough capacity to exploit it.

- The course roadmap moves from logistic regression to shallow networks and then to deep networks. Logistic regression is a useful building block for binary outputs.

## Practice and review

Pick two applications from the lectures and identify input x, target y, and whether the task is regression or classification.

**Watch for:** A network's depth alone does not ensure success; training data, objective, optimization, and evaluation still matter.
