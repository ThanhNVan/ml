# Course 4: Structuring Machine Learning Projects

Choose high-value experiments using clear metrics, data splits, and error analysis.

## What you should be able to do

Diagnose the current bottleneck before changing the model, metric, training data, or system architecture.

## Learning path

### [Week 1: Metrics and diagnosis](week-1/week.md)

Orthogonalization, single-number and satisficing metrics, dev/test design, human-level performance, and avoidable bias shape the next experiment.

### [Week 2: Iteration and transfer](week-2/week.md)

Error analysis, label quality, distribution mismatch, transfer learning, multitask learning, and end-to-end learning guide project decisions.
