# Course 1: Supervised Machine Learning: Regression and Classification

Build a baseline regression model, improve it with multiple features, then move to classification and regularization.

## What you should be able to do

Given labeled data, choose a model and cost function, optimize parameters with gradient descent, inspect learning behavior, and control overfitting.

## Learning path

### [Week 1: Foundations and univariate regression](week-1/week.md)

The first week distinguishes supervised from unsupervised learning, introduces Jupyter notebooks, and constructs one-variable linear regression. The progression from predictions to squared-error cost to gradient descent explains what training actually minimizes.

### [Week 2: Multiple features and model improvement](week-2/week.md)

Vectorization makes multivariate regression efficient. Feature scaling, convergence checks, learning-rate choices, feature engineering, and polynomial terms improve the training process and model fit.

### [Week 3: Classification and generalization](week-3/week.md)

Logistic regression maps a linear score through the sigmoid. Decision boundaries, cross-entropy, gradient descent, overfitting, and regularization connect classification accuracy to generalization.
